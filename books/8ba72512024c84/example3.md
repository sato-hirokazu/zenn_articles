## はじめに

AI時代の開発プロセスにおいて、プロンプト設計は重要なスキルです。本章では、効果的なプロンプト設計のパターンと実践方法を解説します。

## 1. プロンプト設計の基本原則

### 1.1 文脈を明確にする

AIに指示を出す際、背景と目的を明確にすることが重要です。

- **悪い例**: 「ユーザー認証機能を作って」
- **良い例**: 「B2B SaaSアプリケーションの多要素認証機能を実装してください。セキュリティ要件として、パスワード漏洩時のリスク軽減と、規制要件への準拠が必要です」

### 1.2 具体的な制約条件を提示する

制約条件を明確にすることで、AIの生成結果の品質が向上します。

- 使用技術スタック
- パフォーマンス要件
- セキュリティ要件
- 既存コードベースとの整合性

### 1.3 出力形式を指定する

期待する出力形式を事前に伝えることで、再利用可能な成果物が得られます。

```
以下の形式で出力してください：
1. 概要
2. 実装コード
3. テストケース
4. 注意点
```

## 2. 実装タスク向けプロンプトパターン

### 2.1 段階的実装パターン

複雑なタスクは段階的に分割して指示します。

```
ステップ1: データモデルの設計
ステップ2: APIエンドポイントの実装
ステップ3: バリデーションロジックの追加
ステップ4: エラーハンドリングの実装
```

### 2.2 比較検討パターン

複数の実装案を比較させることで、最適な選択ができます。

```
以下の3つのアプローチで実装案を提示してください：
1. 最小実装案（MVP向け）
2. 拡張性重視案（将来の機能追加を想定）
3. 性能最適化案（高トラフィックを想定）
```

### 2.3 リファクタリングパターン

既存コードの改善を依頼する際のパターンです。

```
以下のコードをリファクタリングしてください：
- 可読性向上
- 責務分割の明確化
- テスト容易性の向上
- パフォーマンス改善の余地があれば指摘
```

## 3. テスト設計向けプロンプトパターン

### 3.1 網羅的テスト生成パターン

テストケースを網羅的に生成するパターンです。

```
以下の機能について、以下の観点を全てカバーするテストケースを生成してください：
- 正常系
- 異常系（入力値の境界値、不正な形式など）
- セキュリティ観点（インジェクション、認可など）
- 性能観点（大量データ、同時アクセスなど）
```

### 3.2 境界値分析パターン

境界値テストを重点的に生成するパターンです。

```
以下の入力パラメータについて、境界値分析に基づいたテストケースを生成してください：
- 最小値、最大値
- 境界付近の値
- 無効な値
```

## 4. 設計レビュー向けプロンプトパターン

### 4.1 設計評価パターン

設計案を評価させるパターンです。

```
以下の設計案について、以下の観点で評価してください：
- 保守性
- 拡張性
- 性能
- セキュリティ
- テスト容易性

各観点について、改善提案も併せて提示してください。
```

### 4.2 リスク分析パターン

設計上のリスクを特定するパターンです。

```
以下の設計について、潜在的なリスクを特定してください：
- 単一障害点
- パフォーマンスボトルネック
- セキュリティホール
- 運用上の問題点
```

## 5. ドキュメント作成向けプロンプトパターン

### 5.1 APIドキュメント生成パターン

APIのドキュメントを自動生成するパターンです。

```
以下のAPIエンドポイントについて、開発者向けドキュメントを生成してください：
- エンドポイントの目的
- リクエスト形式とパラメータ
- レスポンス形式
- エラーコードと意味
- 使用例（cURL、JavaScript、Python）
```

### 5.2 技術仕様書作成パターン

技術仕様書を作成するパターンです。

```
以下の機能について、技術仕様書を作成してください：
- 概要と目的
- システム構成図（Mermaid形式）
- データフロー
- 主要コンポーネントの責務
- 非機能要件
- 依存関係
```

## 6. プロンプト設計のベストプラクティス

### 6.1 反復的改善

プロンプトは一度で完璧を目指さず、反復的に改善します。

1. 最初の指示で結果を得る
2. 結果を評価し、不足点を特定
3. プロンプトを改良して再試行
4. 成功したパターンをテンプレート化

### 6.2 具体例の提示

具体例を提示することで、期待する出力形式を明確にできます。

```
以下の例と同じ形式で出力してください：
[良い例の提示]
```

### 6.3 役割の付与

AIに特定の役割を与えることで、専門的な視点を得られます。

```
あなたはセキュリティ専門家として、以下のコードをレビューしてください。
```

### 6.4 思考プロセスの可視化

複雑な問題では、思考プロセスを可視化させることで、質の高い回答が得られます。

```
段階的に考えて、各ステップの根拠を説明しながら回答してください。
```

## 7. この章のまとめ

効果的なプロンプト設計のポイントは以下の通りです。

- 文脈と目的を明確にする
- 具体的な制約条件を提示する
- 出力形式を指定する
- 段階的に指示を出す
- 反復的に改善する
- 成功パターンをテンプレート化する

プロンプト設計は、AI時代のエンジニアにとって必須のスキルです。継続的な学習と実践を通じて、効果的な指示出しの技術を磨いていきましょう。
